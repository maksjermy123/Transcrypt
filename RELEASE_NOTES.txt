================================================================================

macOS:
  1. Extract archive
  2. Run: open dist_release/VoxPaperAi\ Pro.app

  1. Extract archive
  2. Open PowerShell as Administrator
  3. cd proect1
  4. .\tools\build_release_windows.ps1
  5. Run the generated .exe

📞 SUPPORT
================================================================================

Check logs:
  ~/.voxpaperai/logs/app-latest.log

Export diagnostics:
  Settings → Export Diagnostics

Common issues:
  • "File too large" → Split file or edit validator.py
  • "No disk space" → Free up disk (need 2.5x file size)
  • "Network error" → App retries automatically
  • "File corrupted" → Try different file
