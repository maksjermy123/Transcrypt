VOXPAPERAI PRO — УСТАНОВКА НА MACOS БЕЗ APPLE DEVELOPER ID
===========================================================

Это бесплатный вариант распространения приложения.
Приложение не нотариализовано Apple, поэтому macOS может показывать
предупреждения безопасности. Для такого способа установки это ожидаемо.

Главная мысль:
--------------
В большинстве случаев пользователю достаточно:
1. открыть DMG
2. перетащить приложение в Applications
3. открыть его через правый клик -> Open

ЧТО ВНУТРИ DMG
--------------
1. VoxPaperAi Pro.app
2. Ярлык Applications
3. Этот файл с инструкцией
4. DISCLAIMER.txt

ЧТО УЖЕ ВСТРОЕНО В ПРИЛОЖЕНИЕ
----------------------------
Пользователю обычно НЕ нужно отдельно устанавливать:
- Python
- pip
- PyQt
- библиотеки проекта
- Whisper runtime приложения

Приложение уже собрано как обычный `.app`.

ЧТО МОЖЕТ ПОНАДОБИТЬСЯ ДОПОЛНИТЕЛЬНО
-----------------------------------
Некоторые функции зависят от внешних условий:

1. Интернет:
   нужен для YouTube, перевода, чата с ИИ, AI Studio, части обновлений.

2. API key:
   нужен для чата с ИИ и некоторых сценариев перевода.

3. ffmpeg:
   приложение пытается использовать и при необходимости подтянуть его само,
   но если это не удалось, можно установить вручную:

   brew install ffmpeg

4. LibreOffice / Microsoft Word:
   иногда нужны для отдельных сценариев конвертации документов.

ОБЫЧНАЯ УСТАНОВКА
-----------------
1. Откройте файл DMG.
2. Перетащите "VoxPaperAi Pro.app" в "Applications".
3. Дождитесь завершения копирования.
4. Откройте папку "Applications".
5. Не запускайте двойным кликом сразу.
6. Нажмите правой кнопкой мыши по "VoxPaperAi Pro.app".
7. Выберите "Open" / "Открыть".
8. В появившемся окне снова нажмите "Open" / "Открыть".

ПЕРВЫЙ ЗАПУСК
-------------
При первом запуске приложение:
- покажет окно с условиями использования
- попросит подтвердить согласие
- затем откроет основной интерфейс

Это нормальное поведение.

ОБХОД БЛОКИРОВКИ GATEKEEPER
---------------------------
Если macOS пишет, что приложение от неизвестного разработчика:

1. Попробуйте открыть приложение один раз.
2. Откройте:
   System Settings -> Privacy & Security
3. Прокрутите вниз до блока Security.
4. Нажмите "Open Anyway" рядом с VoxPaperAi Pro.
5. Подтвердите запуск паролем.

ЕСЛИ MACOS ПИШЕТ "APP IS DAMAGED" ИЛИ НЕ ДАЕТ ОТКРЫТЬ
-----------------------------------------------------
Иногда это не реальная "поломка", а карантин macOS.

Сделайте так:

1. Откройте Terminal.
2. Выполните команду:

   xattr -dr com.apple.quarantine "/Applications/VoxPaperAi Pro.app"

3. Затем выполните:

   open "/Applications/VoxPaperAi Pro.app"

ЕСЛИ ПРИЛОЖЕНИЕ ВСЕ ЕЩЕ НЕ СТАРТУЕТ
----------------------------------
Проверьте права:

   chmod -R a+rX "/Applications/VoxPaperAi Pro.app"

ПОСЛЕ ЭТОГО СНОВА:

   open "/Applications/VoxPaperAi Pro.app"

ЕСЛИ НЕ РАБОТАЮТ CHAT / AI / ПЕРЕВОД
-----------------------------------
Проверьте:

1. Есть ли интернет
2. Указан ли API key
3. Верно ли выбран провайдер
4. Нет ли rate-limit / 429 / 503 у внешнего сервиса

Важно:
- приложение запускается локально
- но часть возможностей зависит от внешних API и сайтов

ЕСЛИ НЕ РАБОТАЕТ YOUTUBE
------------------------
Возможные причины:
- временные ограничения YouTube
- `HTTP 429`
- изменения на стороне YouTube
- проблемы сети
- отсутствие ffmpeg

Что делать:
1. попробовать снова позже
2. проверить интернет
3. убедиться, что ffmpeg доступен
4. помнить, что fallback через скачивание медиа и Whisper может занять больше времени

ЕСЛИ НЕ РАБОТАЮТ МЕДИА-ОПЕРАЦИИ
-------------------------------
Проверьте:
- установлен ли ffmpeg
- хватает ли места на диске
- доступна ли папка назначения
- нет ли ограничений на запись

ГДЕ ХРАНЯТСЯ ДАННЫЕ ПРИЛОЖЕНИЯ
-----------------------------
На этом Mac приложение может использовать:

1. Application Support:
   ~/Library/Application Support/VoxPaperAi

2. Конфиг:
   ~/.voxpaperai_config.json

3. API keys:
   Keychain macOS

Если приложение уже использовалось на этом же Mac раньше,
оно может подхватить прежние локальные настройки пользователя.
Для нового пользователя на другом Mac это не произойдет.

КАК ПОЛНОСТЬЮ СБРОСИТЬ ПРИЛОЖЕНИЕ
--------------------------------
Во вкладке "Настройки" есть кнопка:

   "Удалить приложение и все данные"

Она предназначена для полного сброса и удаляет:
- данные приложения
- конфиг
- сохранённые ключи чата
- а в собранной версии — и сам пакет приложения после выхода

Перед этим приложение показывает два предупреждения.

ВАЖНЫЕ ОСОБЕННОСТИ
------------------
1. Это версия для Apple Silicon Mac:
   M1 / M2 / M3 / M4

2. Для части функций нужен интернет:
   - YouTube
   - перевод
   - чат с ИИ

3. Для некоторых медиа-операций нужен ffmpeg.
   Если приложение само его не находит, можно установить через Homebrew:

   brew install ffmpeg

4. Это не App Store версия.
   Поэтому предупреждения macOS при первой установке возможны.

МЯГКИЙ ЧЕК-ЛИСТ ДЛЯ ПОЛЬЗОВАТЕЛЯ
--------------------------------
Если хотите просто пройти установку без лишних деталей:

1. Перетащите приложение в Applications
2. Откройте его через правый клик -> Open
3. Если macOS блокирует — Privacy & Security -> Open Anyway
4. Если пишет damaged — выполните:

   xattr -dr com.apple.quarantine "/Applications/VoxPaperAi Pro.app"

5. При первом запуске согласитесь с условиями
6. Для чата и ИИ введите свои API key во вкладке "Настройки"
7. Если не работают медиа-операции — установите ffmpeg

ПОЛЕЗНО
-------
Если приложение было скопировано не в Applications, а на Desktop или в Downloads,
лучше перенести его именно в Applications и запускать уже оттуда.
