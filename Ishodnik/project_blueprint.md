# VoxPaperAi Pro: Текущая техническая карта

Документ описывает фактическое состояние `proect1/` на текущем этапе, а не исторический референс.

> Важно: актуальный код находится только в корневом `src/`. Упоминания чата
> ниже относятся к историческому снимку и не являются функцией текущей версии.

## 1. Назначение

`VoxPaperAi Pro` — настольное приложение для:

- транскрибации через `Whisper`
- обработки медиа через `ffmpeg`
- скачивания через `yt-dlp`
- перевода текста и документов
- конвертации форматов
- чата с ИИ и построения `конспекта / саммари` по артефактам

## 2. Архитектура

- `src/ui` — интерфейс, вкладки, главный window, общие виджеты
- `src/core` — `downloader`, `engine`, `converter`, `translator`, `chat_client`
- `src/utils` — конфиг, key store, runtime, диагностика, очередь тяжёлых задач

Приложение модульное, а не монолитное.

## 4. Очередь задач

Тяжёлые задачи теперь не стартуют хаотично параллельно.

Работает планировщик:

- первая тяжёлая задача стартует сразу
- следующие ставятся в очередь
- очередь отображается глобально в главном окне
- вкладки видят live-статус очереди
- после завершения одной задачи следующая стартует автоматически

Это сделано для стабильности, потому что одновременно могут конкурировать:

- `yt-dlp`
- `ffmpeg`
- `Whisper`
- перевод
- PDF-конвертация

## 5. Whisper и CPU-потоки

Приложение поддерживает:

- ручной выбор числа CPU-потоков
- режим `Auto`

Параметры потоков применяются через:

- `OMP_NUM_THREADS`
- `MKL_NUM_THREADS`
- `OPENBLAS_NUM_THREADS`
- `VECLIB_MAXIMUM_THREADS`
- `NUMEXPR_NUM_THREADS`
- `torch.set_num_threads(...)`

Логи Whisper выводят реальные параметры запуска subprocess.

## 6. Chat / Large Text Pipeline

Большие тексты не отправляются в модель единым безразмерным куском.

Сценарий:

1. текст делится на крупные блоки
2. по каждому блоку строится промежуточный результат
3. промежуточные результаты редуцируются в общий итог

Настраиваемые параметры:

- `max output tokens`
- `temperature`
- `top-p`
- `top-k`
- `seed`
- `timeout`
- `response MIME`
- `Gemini thinking budget`
- размер блока
- overlap
- промежуточные токены
- размер reduce batch

## 7. Google AI Studio

Поддерживается нативно через `Gemini API`, а не через псевдо-OpenAI режим.

Базовая схема:

- API key из `https://aistudio.google.com/app/apikey`
- базовый URL: `https://generativelanguage.googleapis.com/v1beta`
- endpoint генерации: `models/{model}:generateContent`

## 8. Известные внешние ограничения

- YouTube субтитры могут возвращать `HTTP 429`
- некоторые режимы PDF зависят от установленного `LibreOffice` / `Word`
- скорость больших пайплайнов зависит не только от CPU, но и от сети/API-провайдера
