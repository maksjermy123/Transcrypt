# Transcrypt (VoxPaperAi Pro)

Универсальный инструмент для **транскрибации аудио/видео, перевода и конвертации** — в двух вариантах:

| | Веб-версия (бесплатно, без установки) | Десктоп-версия (Python + PyQt) |
|---|---|---|
| Где работает | Прямо в браузере (Whisper через WASM/WebGPU) | macOS / Windows / Linux — нативно |
| Установка | Не нужна — открыть сайт, пройти гид | Запустить `engine_server.py` + открыть сайт |
| Ресурсы | CPU/GPU/RAM пользователя (вкладка браузера) | CPU/GPU/RAM пользователя (нативный Python) |
| Деплой | `web/` → GitHub Pages | Локально на компьютере пользователя |

---

## 🌐 Веб-версия (новая, рекомендуется для большинства)

**Адрес после деплоя:** `https://maksjermy123.github.io/Transcrypt/`

**Как это работает:**
1. Пользователь открывает сайт → видит интерактивный гид из 6 шагов
2. Гид объясняет, что будут задействованы ресурсы его ПК
3. Кнопка «Установить движок» → браузер качает transformers.js + WASM (~25 МБ) с CDN
4. Кнопка «Выбрать Whisper» → пользователь выбирает Tiny (40 МБ) или Base (77 МБ)
5. Модель качается и кешируется в IndexedDB браузера
6. Финал: пользователь добавляет сайт в закладки (Ctrl/Cmd+D)
7. **При следующем открытии** — движок и модель мгновенно подтягиваются из кеша

**Вкладки рабочей страницы:**
- 🎙 **Транскрипция** — drag&drop аудио/видео → Whisper → экспорт SRT/VTT/TXT
- 🔄 **Конвертер** — изображения PNG/JPEG/WebP + текстовые файлы
- 🌍 **Перевод** — 14 языков через бесплатный MyMemory API

**Исходный код:** папка [`web/`](./web/)

**Локальный запуск веб-версии:**
```bash
cd web
bun install
bun run dev
# открыть http://localhost:3000
```

## 🖥 Десктоп-версия (Python + PyQt6)

Классическое настольное приложение для macOS / Windows / Linux.

**Возможности:**
- Транскрибация локальных файлов, YouTube и импорт ссылок из `.txt`
- Скачивание видео/аудио, очистка аудио, вшивание субтитров
- Конвертация медиа/документов/изображений
- Перевод Google / DeepL, включая PDF FAST и PDF LAYOUT
- Локальный движок `engine_server.py` для работы с веб-интерфейсом

**Запуск на macOS (dev-режим):**
```bash
./run_dev.command            # запустить приложение
./run_dev.command --tests    # прогнать тесты
```

**Release-сборка macOS:**
```bash
./.venv/bin/python -m pip install -r requirements-build.txt
./tools/build_release.sh
```

**Запуск локального движка для веб-версии:**
```bash
python engine_server.py
# Откройте http://127.0.0.1:8765/api/health — увидите статус
```

**Структура:**
- `src/` — Python-код (core, ui, utils)
- `engine_server.py` — HTTP-мост между веб-интерфейсом и локальным железом
- `docs/site/index.html` — старый веб-интерфейс (для локального движка)
- `tools/build_release.sh` — релизная сборка `.app + .dmg`
- `tests/` — unittest-наборы

## Деплой веб-версии на GitHub Pages

Деплой автоматизирован через GitHub Actions (`.github/workflows/deploy-web.yml`).

**Настройка (один раз):**
1. Repo → Settings → Pages → Source: **GitHub Actions**
2. Любой пуш в `main`, изменяющий `web/`, триггерит пересборку и публикацию
3. Через ~2 минуты сайт доступен на `https://maksjermy123.github.io/Transcrypt/`
