# VoxPaperAi Pro

Десктопное приложение на `Python + PyQt6` для транскрибации, медиа-обработки, перевода и конвертации (macOS).

## Что умеет

- `Транскрибация`: локальные аудио/видео, YouTube и импорт ссылок из `.txt`
- `Медиа`: скачать видео/аудио, очистить аудио, вшить субтитры
- `Конвертер`: медиа, документы и базовые форматы изображений
- `Перевод`: `Google / DeepL`, включая `PDF FAST` и `PDF LAYOUT`

## Ключевые особенности текущей версии

- Живая очередь тяжёлых задач вместо конфликтующего параллельного запуска
- Единый блок очереди задач в главном окне
- Цветные статусы строк и явные этапы пайплайна
- Автоматическая установка `ffmpeg/ffprobe` в dev-режиме
- Автовыбор числа CPU-потоков для Whisper
- Подстройка светлой/тёмной темы под систему
- Диагностика среды в `Настройках`
- Устойчивый перевод: чанки по границам предложений, ретраи с backoff
  и резервный Chrome-TLS канал (обход HTTP 429 от Google)

## Известные особенности

- YouTube может возвращать `HTTP 429` на скачивание субтитров. В этом случае приложение переходит к fallback-сценарию: скачивает медиа и делает распознавание через Whisper.
- Для `PDF LAYOUT` на финальной стадии может понадобиться `LibreOffice` или `Microsoft Word`, в зависимости от сценария экспорта.
- Скорость полного пайплайна зависит не только от CPU, но и от `yt-dlp`, `ffmpeg`, сети и провайдера перевода.

## Troubleshooting: HTTP 429 / HTTP 403 (YouTube)

YouTube ограничивает частые запросы и требует браузерный TLS-отпечаток. Приложение автоматически:

- использует TLS-impersonation (`curl-cffi`, маскировка под Chrome);
- применяет клиент `mweb` с решателем JS-челленджей (EJS + Deno);
- повторяет скачивание субтитров и медиа до 3 раз с паузами;
- делает паузу между URL-задачами в очереди;
- перевод (Google) автоматически уходит на резервный канал с Chrome-TLS
  при блокировке основного.

Требования для скачивания с YouTube:

1. Пакет `curl-cffi` (уже в requirements.txt).
2. **Deno** — JS-рантайм для решения челленджей YouTube: `brew install deno`.

Если ошибка повторяется:

1. Подождите 10–15 минут — блокировка 429 обычно снимается сама.
2. Обновите yt-dlp (Настройки → «Обновить загрузчик»).
3. Уменьшите количество задач в очереди за один запуск.

## Локальный запуск на macOS (без установки)

```bash
cd /path/to/proect1
./run_dev.command            # запустить приложение
./run_dev.command --tests    # прогнать тесты
```

Скрипт сам проверит/установит ffmpeg и запустит приложение из `.venv`.

## Release-сборка macOS

```bash
cd /path/to/proect1
./.venv/bin/python -m pip install -r requirements-build.txt
./tools/build_release.sh
```

Сценарий сборки:

- берёт иконку из `src/ui/assets/logo.png`
- генерирует `resources/icon.icns`
- собирает `VoxPaperAi Pro.app`
- упаковывает приложение в `VoxPaperAi_Pro_Installer.dmg`

## Структура проекта

- `src/ui` — интерфейс и вкладки
- `src/core` — движки обработки, downloader, converter, translator
- `src/utils` — конфиг, диагностика, runtime-хелперы
- `docs` — технические документы
- `tools/build_release.sh` — релизная сборка `.app + .dmg`

`src/` — единственный актуальный исходный код.

## Тестирование

Базовая быстрая проверка:

```bash
python3 -m compileall src
```

UI/логика:

```bash
python -m unittest discover tests
```
