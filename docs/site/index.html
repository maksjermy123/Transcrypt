Локальное десктопное приложение для обработки медиа: транскрибация через Whisper, перевод через Google / DeepL, конвертация форматов — без облачных зависимостей.

Что умеет VoxPaperAi Pro

Четыре мощных модуля в одном окне

🎙

Транскрибация

Локальные аудио/видео файлы, YouTube-ссылки, импорт URL из .txt. Автовыбор CPU-потоков и модели Whisper.

Whisper · OpenAI
🎬

Медиа-обработка

Скачивание видео/аудио с YouTube, очистка аудио-дорожки, вшивание субтитров в видео.

yt-dlp · ffmpeg
🔄

Конвертер

Конвертация медиа-файлов, документов и базовых форматов изображений между любыми популярными форматами.

ffmpeg · LibreOffice
🌍

Перевод

Google и DeepL переводчики. Режимы PDF FAST и PDF LAYOUT с сохранением форматирования.

Google · DeepL
📋

Живая очередь

Единый блок очереди задач: цветные статусы, прогресс пайплайна, последовательное выполнение без конфликтов.

Task Queue
🛡

Устойчивость

Автоматические ретраи с backoff, резервный Chrome-TLS канал при HTTP 429 от Google, TLS-impersonation для YouTube.

curl-cffi · Deno

Установка

Два варианта: готовый .dmg или запуск из исходников

📦 Готовый установщик

1

Скачайте .dmg

Из раздела Releases на GitHub

2

Перетащите в Applications

Стандартная установка macOS

3

Запустите

При первом запуске: ПКМ → Открыть

👨‍💻 Из исходников

1

Клонируйте репо

git clone https://github.com/maksjermy123/Transcrypt.git
2

Запустите

cd Transcrypt && ./run_dev.command
3

Тесты

./run_dev.command --tests

Системные требования

ОС macOS 12+ (Monterey и выше)
Python 3.10 – 3.12
Процессор Intel или Apple Silicon
ОЗУ 8 GB+ (16 GB для large модели)
Диск ~2 GB (с моделями Whisper)
Дополнительно ffmpeg, Deno (brew install)
