Как запустить:
  1. Распакуйте скачанный ZIP-архив Transcrypt-main.zip.
  2. На macOS: запустите файл run_mac.command (при первом открытии: ПКМ → Открыть).
  3. На Windows: запустите файл run_windows.bat.
  4. На Linux: запустите ./run_linux.sh.
  5. Сайт автоматически подключится к запущенному движку!
