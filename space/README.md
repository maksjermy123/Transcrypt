# 🎙 VoxPaperAi Pro — Web Edition

Бесплатная веб-версия приложения VoxPaperAi Pro.

## Возможности

- **Транскрибация** — распознавание речи через Whisper (tiny / base / small / medium)
- **Перевод** — Google Translate для текста и файлов (.txt, .srt, .vtt)
- **Очистка аудио** — шумоподавление, фильтрация частот, нормализация
- **Конвертер** — конвертация аудио/видео между популярными форматами

## Ограничения веб-версии

- Работает на CPU (без GPU) — модели medium и large могут быть медленными
- Максимальный размер загружаемого файла ограничен
- Нет поддержки YouTube-ссылок (только загрузка файлов)
- Нет конвертации документов (PDF/DOCX)

Для полного функционала скачайте [десктопное приложение](https://github.com/maksjermy123/Transcrypt/releases).
